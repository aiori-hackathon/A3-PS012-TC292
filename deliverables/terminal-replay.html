Recorded terminal replay

Recordings of the real runs, with silent gaps compressed. Play, scrub the bar, switch 1x / 2x / 4x, space toggles. To re-run it yourself: install the two manual prerequisites (Docker and uv, see the README), then uv run --directory src python run_demo.py.
